# 声音日记微信小程序

根据《声音日记微信小程序需求分析》实现的课程项目。包含首页、录音与编辑、历史筛选、详情播放、收藏、删除、分类统计和近七天记录统计。

## 运行

1. 在微信开发者工具中选择“导入项目”，选择本文件夹。
2. `project.config.json` 默认使用 `touristappid` 供本地预览。需要真机调试或提交时，在开发者工具中换成自己的小程序 AppID。
3. 在真机上允许麦克风权限。点击“录音”开始，暂停或继续后完成录音，试听并填写标题，点击保存。

项目无需第三方依赖或后端服务。音频文件通过 `wx.saveFile` 保存在设备的小程序文件空间，日记信息通过 `wx.setStorageSync` 保存。换设备、卸载小程序或清理本地数据后，记录不会同步恢复。

## 功能说明

- 录音：最长 10 分钟，支持开始、暂停、继续、停止和时长显示。
- 试听与播放：支持播放、暂停、重播及拖动进度。
- 编辑：标题、文字描述、日期、分类、心情。
- 历史：按日期、分类筛选，查看收藏。
- 详情：播放、收藏或删除日记。删除时同步移除关联录音文件。
- 统计：总数、总时长、收藏数、分类占比及近七天记录数。

录音页的动态条形图为录音状态动画，不代表精确声压或实时音频采样值。微信录音 API 输出压缩音频帧，本项目未引入解码库。

## 验收建议

在微信开发者工具及真机中依次验证：麦克风授权、录音暂停继续、保存后重启小程序、播放进度、分类日期筛选、收藏、删除及统计刷新。录音和持久化文件行为以真机结果为准。
